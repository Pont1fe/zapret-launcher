# Готовые наборы сайтов

`sites.json` — наборы на вкладках «Готовые наборы» (домены zapret и маршруты VPN). Лаунчер скачивает этот файл из ветки `main` при каждой проверке обновлений, так что правка здесь доходит до всех без нового релиза.

Если сервис завёл новый домен, достаточно дописать его в набор: у тех, у кого набор включён, лаунчер сам добавит домен в «Обходить» и в маршруты VPN (и перезапустит обход). Если пользователь убрал из набора хоть один домен, набор считается выключенным, и его список лаунчер не трогает.

## Поля набора

| Поле | Что это |
|---|---|
| `name` | Название; по нему лаунчер узнаёт набор при обновлении — **не переименовывайте** существующие наборы |
| `group` | Вкладка — одна из `groups` |
| `mark`, `color` | Значок: 1–3 символа на плашке цвета `#RRGGBB` |
| `domains` | Домены без `https://`, `www.` и путей, строчными буквами; поддомены учитываются сами |
| `apps` | Программы для маршрутов VPN: только имя файла, `Spotify.exe` (без папки) |
| `vpnOnly` | `true` — сервис закрыт по стране, zapret не поможет: набор показывается только в маршрутах VPN |

Набор с ошибкой (неизвестная вкладка, домен не в нормальной форме, путь вместо имени программы) лаунчер пропустит, остальные будут работать. Тесты (`tests/run.ps1`) проверяют этот файл при каждой сборке, так что ошибка будет видна сразу в GitHub Actions.

`format` меняется только вместе с кодом лаунчера: версии, которые не знают новый формат, оставят у себя прежние наборы.

Убранный из файла набор просто исчезнет с вкладок; домены, которые пользователь уже добавил, останутся в его списках.
